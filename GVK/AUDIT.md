# Аудит наследия (базовая линия)

Базовая линия: проект не собирался (нет pom.xml/исходников), тестов нет. На момент аудита в main: 4 файла + GVK/PLAN.md.

| файл | вердикт | обоснование | доказательство |
|---|---|---|---|
| docs/TZ.md | KEEP | техническое задание, источник требований | сообщение владельца указывает его как ТЗ |
| LICENSE | KEEP | Public Domain, не противоречит ТЗ | текст файла: public domain dedication |
| README.md | REWRITE | одна строка заголовка, не соответствует Части 11 протокола | `wc -c README.md` = 15 байт; требуется двухчастный EN/RU README |
| .gitignore | REFACTOR | maven-шаблон, но отсутствуют dist/, env.sh, IDE-секции шаблона Части 10.3 | diff с шаблоном PROTOCOL.md 10.3: нет dist/, *.zip, env.sh, .idea/ |

Решения по неоднозначностям (правило выбора по умолчанию):
1. ТЗ предписывает Qt/PySide6; протокол владельца (Часть 1.5/10) задаёт единый стек Java 21 + Swing. Приоритет у протокола; весь функциональный объём ТЗ сохраняется.
2. PDF/X-4: полноценная сертификация недоступна без внешних библиотек; реализуется максимально близкий печатно-готовый PDF (векторный, bleed 3 мм, crop/registration marks). Решение детализирует фрагмент 004.
3. Хранилище настроек: вместо SQLite/QSettings — обычный Properties-файл в per-user директории (протокол запрещает БД; офлайн, переносим).
